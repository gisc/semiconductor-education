# The Thinking Sand

An interactive chip adventure for ages 14+ - semiconductor technology literacy for secondary-school learners, bridging Computing, Physics and Economics.

**Live site:** https://gisc.github.io/semiconductor-education/

## What it is

A single-page, dependency-free website (plain HTML, CSS and JavaScript) that tells the story of how we taught sand to think - through hands-on activities rather than static text:

1. **Chips are everywhere** - a tap-to-open chip hunt across everyday objects, plus a "chip family" explorer (processors, memory, image sensors, power chips).
2. **The magic sand** - a doping lab (place boron/phosphorus atoms, get P-type/N-type verdicts) and a diode one-way-valve demo.
3. **The tiny switch** - a transistor gate toggle and an AND/OR/XOR/NAND logic playground with live truth tables.
4. **Printing the invisible** - a six-step chip-fabrication walkthrough and a Moore's-law time slider.
5. **Why AI is hungry** - a CPU vs GPU parallel-processing race (with honest "made-up ratios" caveats).
6. **The chip chessboard** - a chip's passport across the global supply chain, including Singapore's role and Japan's Rapidus bet.
7. **Checkpoint quiz** - five misconception-first questions with explanations.

## Using it in class

Open the live site on any phone or laptop - no installs, accounts or tracking. Discussion prompts are at the end of the page. Everything runs locally in the browser.
